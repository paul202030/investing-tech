# Ha Yeung Dog Days

Start every session by reading `HANDOFF.md` in this folder, every entry.

Before the session ends or work is handed off, **append** a new entry to `HANDOFF.md` (`## #N · date · session link`): what changed, what you learned, what's next. It is an append-only log: never rewrite or delete earlier entries; correct them in a new entry instead. Commit and push it with the work.

Give the user a cost estimate before large changes, and offer to split big work into smaller releases.
